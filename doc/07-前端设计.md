# 07 · 前端设计

> 最后更新：2026-11-04

## 一、三端定位

| 工程 | 目录 | 面向 | 技术栈 | 默认端口 / 产物 |
|---|---|---|---|---|
| 管理端 | `admin-web` | 管理员 | Vue 3 + Vite + Element Plus + TypeScript + Pinia | dev `:80`；构建 `dist-*` |
| 用户端 | `user-web` | 游客 / 会员 | Vue 3 + Vite + Element Plus + TypeScript + Pinia | dev `:3001`；构建 `dist` |
| 移动端 | `tender-app` | 移动用户 | UniApp（Vue 3） | H5 `dist/build/h5`；可打包 App |

三端共用后端：`/admin-api`（管理端）、`/app-api`（用户端会员接口）。公告/项目查询走 `/admin-api/notice/**`（匿名）。

## 三、路由与权限

### 3.1 用户端

| 路径 | 页面 | 鉴权 |
|---|---|---|
| `/` | 首页 | 公开 |
| `/notice` | 公告列表 | 公开 |
| `/notice/:id` | 公告详情 | 公开 |
| `/my-bids` | 我的投标 | 需登录 |
| `/login` / `/register` | 登录/注册 | 公开（已登录跳首页） |
| `/ai-search` / `/tag/explore` / `/favorite` | 占位页 | 公开 |

守卫：`meta.requiresAuth` → 未登录跳 `/login?redirect=...`；已登录访问登录/注册页跳首页。

### 3.2 管理端

- 静态路由：登录、首页、个人中心、重定向、错误页。
- 业务菜单：登录后从 `system_menu` 动态生成，`component` 对应 `src/views/**`。
- 新增页面必须同时插菜单；`component` 写错会显示空白页。

### 3.3 移动端

`pages.json` 注册页面：首页、公告列表、公告详情、我的投标、登录。H5 路由与用户端一致。

## 四、API 层规范

### 4.1 实例划分

| 实例 | baseURL | 用途 | Token |
|---|---|---|---|
| `user-web/src/api/request.ts` | `/admin-api` | 公告、项目 | 不携带 |
| `user-web/src/api/app-request.ts` | `/app-api` | 会员、投标 | 自动 `Authorization: Bearer <token>` |
| `admin-web` axios | `VITE_BASE_URL + /admin-api` | 管理端全部 | 自动携带 ADMIN Token |

### 4.2 响应处理

- 后端统一 `CommonResult`：`{ code, msg, data }`，`code=0` 成功。
- 用户端拦截器直接返回 `data`；`code !== 0` reject。
- 管理端兼容 `code=0/200`；401 清 Token 并跳登录。
- `user-web` 在 401 时清除登录态并跳转 `/login?redirect=...`。

### 4.3 类型

- `user-web/src/types.ts` 与后端 `NoticeRespVO` / `ProjectDetailRespVO` / `BidProjectRespVO` 对齐。
- 新增字段先改后端 VO，再同步前端类型；不要用 `any` 兜底。

### 4.4 时间

后端 Jackson 配置为 **epoch 毫秒**。前端统一用 `utils/format` 格式化，不要直接 `new Date(str)`。

## 六、状态管理

- `user-web`：登录态存 `localStorage`（`tender_member_token` / `tender_member_profile`）；页面内状态用 `ref` / `reactive`。Pinia 已安装，当前未强制使用。
- `admin-web`：Pinia 管理用户、权限、字典、标签页等；Token 存 `localStorage`。
- 跨页面共享优先用路由参数/查询参数；不要滥用全局状态。

## 七、组件与样式规范

### 7.1 组件

- 组件名 PascalCase；页面放 `views`，可复用组件放 `components`。
- Props 明确类型与默认值；事件用 `emit`，不直接改父组件状态。
- 表格/表单优先复用 `admin-web` 的 `Table` / `Search` / `Dialog` 组件。

### 7.2 样式

- 用户端使用 `styles.css` 中的 CSS 变量（颜色、间距、圆角）。
- 管理端使用 Element Plus 主题变量，避免硬编码颜色。
- 移动端使用 `rpx`，设计稿宽度 750。
- 类名使用 kebab-case；避免深层嵌套选择器。

### 7.3 可访问性

- 图片有 `alt`；按钮有可读文本或 `aria-label`。
- 表单错误提示与字段关联；键盘可操作。
- 颜色对比度满足 WCAG AA。
