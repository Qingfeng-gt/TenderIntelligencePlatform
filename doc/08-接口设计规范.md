# 08 · 接口设计规范

> 最后更新：2026-11-04

## 一、URL 与方法

| 规则 | 示例 |
|---|---|
| 资源名用复数、小写、短横线 | `/notice/page`、`/bid-project/list` |
| 查询用 GET，创建用 POST，更新用 PUT/POST，删除用 DELETE | `POST /bid-project/create` |
| 路径前缀区分端 | `/admin-api/**` 管理端；`/app-api/**` 用户端 |
| 不在 URL 中放动词堆叠 | 用 `/notice/project/page`，不用 `/getProjectPage` |
| 分页用 `pageNo` / `pageSize` | `/notice/page?pageNo=1&pageSize=10` |
| 资源 ID 用 `id` 查询参数 | `/notice/detail?id=123` |

## 二、统一返回

```json
{
  "code": 0,
  "msg": "",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | `0` 成功；非 0 为业务错误码 |
| `msg` | string | 用户可读错误提示；成功为空串 |
| `data` | any | 业务数据；无数据时为 `null` / `true` |

分页数据：

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "total": 20,
    "list": []
  }
}
```

- 后端统一返回 `CommonResult<T>`。
- 分页统一 `PageResult<T>`：`total` + `list`。
- 前端只依赖 `code` 判断成功，不解析 `msg` 做逻辑。

## 三、鉴权

| 端 | 请求头 | 令牌类型 | 获取方式 |
|---|---|---|---|
| 管理端 | `Authorization: Bearer <ADMIN_TOKEN>` | ADMIN | `/admin-api/system/auth/login` |
| 用户端 | `Authorization: Bearer <MEMBER_TOKEN>` | MEMBER | `/app-api/member/auth/login` |

规则：

- `/admin-api/**` 与 `/app-api/**` 的令牌按 `UserTypeEnum` 隔离，不能混用。
- 匿名接口用 `@PermitAll` 标注；`application.yaml` 的 `tender.security.permit-all-urls` 作冗余兜底。
- 当前匿名接口：
  - `/admin-api/notice/**`（公告/项目门户查询）
  - `/app-api/member/auth/login|register|logout`
  - `/app-api/ai-search/**`、`/app-api/tag/**`（规划中）
- 管理端采集接口需要 ADMIN Token；匿名访问返回 401。

## 四、参数与校验

- 请求体用 JSON（文件上传除外）。
- 入参 VO 使用 `@Schema` 描述；校验用 `@NotNull` / `@NotBlank` / `@Size` / `@Min` 等。
- Controller 类加 `@Validated`，请求体加 `@Valid`。
- 业务校验失败抛 `ServiceException`，由全局异常处理转 `CommonResult`。
- 查询参数为空时使用 `ifPresent` 语义，不把空串当有效条件。

## 五、时间与金额

| 类型 | 约定 |
|---|---|
| 时间 | 后端 Jackson 输出 **epoch 毫秒**；前端统一格式化 |
| 金额 | `decimal(18,2)`，单位 **万元**；接口字段名 `budget` / `priceCeiling` / `depositAmount` |
| 日期范围 | `publishTimeGreaterThan`（含）、`publishTimeLessThan`（不含） |

## 六、错误码

格式：`1-XXX-XXX-XXX`。业务模块区间与示例见 [04 后端设计 §9](04-后端设计.md#九错误码)。

| 错误码 | 含义 |
|---|---|
| `1_004_000_001` | 注册用户名已存在 |
| `1_004_000_002` | 会员不存在 |
| `1_060_001_000` | 公告不存在 |
| `1_060_002_000` | 项目不存在 |
| `1_070_100_000` | 投标项目不存在 |
| `1_070_100_001` | 同一公告重复发起投标 |
| `1_070_100_002` | 投标状态迁移非法 |
| `1_080_100_000` | 采集站点不存在 |
| `1_080_100_001` | 采集站点未启用 |

约定：

- 错误码只增不改，不复用。
- 新增模块先分配区间，再在 `ErrorCodeConstants` 中登记。
- 不把异常堆栈或 SQL 信息返回给前端。

## 七、幂等与并发

| 场景 | 约定 |
|---|---|
| 采集写入 | `source_url` 唯一 + upsert；重复请求不产生重复公告 |
| 项目归并 | `project_key` 唯一；冲突后重查 |
| 企业 | `name_hash` 唯一 |
| 投标创建 | 同一用户 + 公告只允许一个在办项目 |
| 采集触发 | 站点已有 `RUNNING` 任务时跳过 |
| 分布式锁 | 需要时使用 Lock4j / Redisson |

### 8.5 会员管理（ADMIN）

| 方法 | 路径 | 参数 | 返回 |
|---|---|---|---|
| GET | `/admin-api/member/user/page` | `pageNo`、`pageSize`、`username`、`nickname`、`mobile`、`status` | `PageResult<MemberUserRespVO>` |
| GET | `/admin-api/member/user/get` | `id` | `MemberUserRespVO` |

## 九、接口文档

- 本地启动后端后访问 `http://127.0.0.1:48080/doc.html`。
- 每个 Controller 使用 `@Tag`，方法使用 `@Operation`，参数使用 `@Parameter` / `@Schema`。
- 新增接口必须补文档注解；匿名接口标注 `@PermitAll` 并在文档中说明。

## 十、版本与兼容

- 当前无 URL 版本号；通过新增字段/新增接口保持兼容。
- `NoticeApi` 是跨模块契约：**冻结后只加不改**；变更需同步 crawler / bid / 前端。
- 删除字段/接口必须先确认无调用方，并在文档中记录迁移说明。
- 项目未上线阶段可直接删除旧接口（P0 已删除 `/notice/list|get|stats`）。
