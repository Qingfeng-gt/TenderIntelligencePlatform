# 13 · 安全与合规

> 最后更新：2026-11-04

## 一、认证与授权

| 端 | 机制 | 实现 |
|---|---|---|
| 管理端 | OAuth2 Bearer Token（ADMIN） | `system` 模块；`/admin-api/**` |
| 用户端 | OAuth2 Bearer Token（MEMBER） | `member` 模块；`/app-api/**` |
| 匿名接口 | `@PermitAll` + `tender.security.permit-all-urls` | 公告/项目查询、登录/注册 |
| 定时任务 | 进程内调用，`@TenantIgnore` | 采集任务 |

规则：

- ADMIN 与 MEMBER 令牌按 URL 前缀 + `UserTypeEnum` 双向隔离，不能混用。
- 管理端业务接口（采集、系统管理）必须登录；当前权限粒度到「是否管理员」，尚未引入 `@PreAuthorize` 权限点。
- 用户端投标接口必须登录，并校验 `userId` 防越权。
- 匿名接口只读，不提供写操作（登录/注册/登出除外）。

## 三、数据安全

| 数据 | 风险 | 当前措施 | 建议 |
|---|---|---|---|
| 联系人电话 `contact_phone` | 匿名可读 | 随公告详情返回 | 按会员等级脱敏；或详情页隐藏中间位 |
| 企业联系人 | 未来可聚合 | 表已建，未开放接口 | 对外接口脱敏 |
| 密码 | 泄露 | BCrypt 哈希 | 不记录日志；不返回 |
| Token | 泄露 | Bearer + Redis 存储 | HTTPS；不写日志；设置过期 |
| 数据库密码 | 泄露 | 本地配置文件 | 生产用环境变量/配置中心 |
| LLM API Key | 泄露 | `${DEEPSEEK_API_KEY:}` | 只走环境变量，不提交 |

通用：

- 生产强制 HTTPS。
- 不在日志、错误信息、前端代码中暴露密钥。
- 导出/批量接口需鉴权 + 限流（当前未实现）。
- 数据库账号最小权限。

## 四、采集合规

采集对象是**政府公开发布**的招投标公告。

1. **遵守 robots**：接入新源前检查 `/robots.txt`，`Disallow` 路径不采。
2. **限速**：详情页默认 3 秒间隔，单线程串行；不并发打源站。
3. **不绕过访问控制**：不模拟登录、不使用账号凭据、不绕过验证码；源站要求验证码时中止本轮。
4. **不下载附件**：只保存附件直链与元信息，下载行为发生在用户与源站之间。
5. **不二次分发**：正文片段仅用于阅读与检索，不做商业分发。
6. **保留溯源**：每条公告保留 `source_platform` + `source_url`，可回源核对。
7. **最小采集**：只采公告正文与结构化字段，不采用户中心/投标系统后台等非公开区域。

## 五、OWASP 检查清单

| 风险 | 检查项 | 当前状态 |
|---|---|---|
| 失效的访问控制 | 管理接口需 ADMIN；投标校验 userId | ✅ 基本实现；权限点待补 |
| 加密失效 | HTTPS、密码哈希、Token 过期 | 🚧 生产 HTTPS 待配置 |
| 注入 | MyBatis 参数化；无字符串拼接 SQL | ✅ |
| 不安全设计 | 匿名只读、写接口鉴权 | ✅ |
| 安全配置错误 | 默认密码、Actuator 暴露、CORS | 🚧 生产需收紧 |
| 易受攻击组件 | 依赖版本、CVE 扫描 | 🚧 待接入 |
| 身份认证失效 | 验证码、登录失败处理 | ✅ 基本实现 |
| 软件和数据完整性 | CI 构建、依赖锁定 | ✅ 部分 |
| 日志监控不足 | 访问/异常日志、采集日志 | ✅ 基本实现 |
| SSRF | 采集 URL 来自配置，不由用户输入 | ✅ |

## 六、密钥与配置

| 密钥 | 位置 | 要求 |
|---|---|---|
| 数据库密码 | `application-local.yaml` | 生产改环境变量 |
| Redis 密码 | `application-local.yaml` | 生产启用 |
| `DEEPSEEK_API_KEY` | 环境变量 | 不提交 |
| OAuth2 客户端密钥 | `tender.sql` 种子 | 生产替换 |
| API 加密密钥 | `application.yaml` | 当前关闭；启用前评估 |

提交前检查：

```bash
git diff --cached | grep -iE "password|secret|api[_-]?key|token" 
```

> 已知误报：配置里的示例值/占位符；确认不是真实密钥。

## 七、审计与响应

- 登录日志：`system_login_log`。
- 操作日志：`system_operate_log`。
- API 访问/异常：`infra_api_access_log` / `infra_api_error_log`。
- 采集审计：`crawler_task` / `crawler_fetch_log` / `crawl_raw`。
- 安全事件响应：
  1. 立即停用相关接口/令牌；
  2. 保留日志与快照；
  3. 修复后重新发版；
  4. 记录事件与改进项。
