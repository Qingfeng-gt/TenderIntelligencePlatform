## 这是什么

一个**招投标情报平台**：从政府法定公开平台采集招标/中标公告，归一、去重、结构化入库，让用户**直接搜索关键词就能全网查看标讯、寻找商机**，并围绕标讯管理自己的投标。

| 项 | 说明 |
|---|---|
| 对标产品 | 标标达（`www.biaobd.com`）、千里马招标网、剑鱼标讯、立达标讯 |
| 平台名称 | 后端 Swagger 标题「招投标情报平台」；用户端前端品牌名「标讯通」（暂定，见下方命名说明） |
| 当前阶段 | 一期已交付（采集 + 检索 + 投标闭环）；订阅推送、企业画像、监控等为规划中 |
| 技术形态 | Spring Boot 3.5 多模块后端（`backend/`）+ 两个独立 Vue 3 前端（`user-web/`、`admin-web/`） |

**一句话链路**：源站 → 适配器采集 → `notice` 表去重入库 → 用户端检索浏览 → 发起投标 → 状态流转。

> **⚠️ 命名说明（暂定，未修改）**：「标讯通」是用户端前端的**当前**品牌名。已知该名称**已被他人使用**（同业存在同名产品），后续是否改名**待定**；确定的只是一条底线——**最终名称不得与现有产品冲突**。在改名之前，文中出现的「标讯通」一律指 `user-web/` 这个工程，不代表商标可用性。后端 Swagger 标题「招投标情报平台」是功能描述而非品牌名，同样非最终定名。

## 阅读约定

- **口径**：所有技术描述**以当前已实现代码为准**。尚未实现的能力一律显式标注为「规划中」，不写成现状。规划数据模型（`08`）与现状模型（`07`）分文件存放，就是为了避免混淆。
- **状态标记**：✅ 已实现 / ⚠️ 部分实现或存在风险 / ⛔ 规划中或未实现。
- **路径引用**：正文中的类名、接口路径、配置项、表字段均取自源码，可直接检索。仓库相对路径（如 `backend/tender-module-crawler/...`）表示文件位置。
- **交叉链接**：文档间用相对路径互链，可点击跳转。
