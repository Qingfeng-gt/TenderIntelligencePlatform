### 重新生成图表

```bash
cd doc/diagrams

# 需要 Node.js；首次会下载 mermaid-cli
npx -y @mermaid-js/mermaid-cli -i architecture.mmd -o architecture.svg
```

> 如果本机代理未启动，先临时移除代理环境变量：
> `env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY npx ...`

## 四、文档约定

1. **路径与类名**：使用仓库相对路径；类名使用全限定名或 `模块/类名`。
2. **代码片段**：只放关键片段，完整实现以源码为准。
3. **图**：优先使用 Mermaid；复杂架构图保留 `.mmd` 源文件，便于修改。
4. **状态标记**：`✅ 已实现`、`🚧 进行中`、`⛔ 规划中`。
5. **数据量**：文档中的条数均为开发库 2026-11-04 的快照，不是容量承诺。
6. **变更同步**：修改表结构、接口、模块边界时，必须在同一个提交中更新对应文档。
