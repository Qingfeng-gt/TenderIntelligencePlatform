| 项 | 说明 |
|---|---|
| 清单范围 | 全国公开招投标/采购信息平台总清单（国家级 + 31 省级 + 行业央企 + 商业资讯），2026-09 整理 |

**接入优先级约定**（本项目口径，非原表内容）：

| 级别 | 含义 |

## 六、采集可达性实测

> 来源：2026-09 对目标站点的一次性可达性实测。**结论有时效性** —— 站点改版、加 WAF、换接口都会让结论失效，接入前务必重新实测（尤其贵州两站已出现过改版为 zcy 的情况）。

### 6.1 实测结论

| 站点 | 列表可采 | 详情可采 | 结论 |
|---|---|---|---|
| **中国政府采购网** `www.ccgp.gov.cn` | ✅ 静态 HTML `/cggg/dfgg/{gkzb,zbgg,gzgg,xjgg}/` | ✅ 全文在 `#noticeArea` | **主源，已接入**。政府公开数据、服务端渲染、字段齐全（项目编号/预算/采购人/代理/联系人/开标时间） |
| 政采云搜索 `search.ccgp.gov.cn` | ⛔ 返回「频繁访问」限流页 | —— | **不可用**：IP 级限流 |
| **贵州省招标投标公共服务平台** `ztb.guizhou.gov.cn` | ⚠️ JSON 接口 `/api/trade/search`，当前返回 0 条 | ✅ `/api/trade/GetDetail/{Id}` 可用 | **已接入**，适配器就绪；源站列表数据下线中，恢复后自动生效 |
| 千里马招标网 `qianlima.com` | ✅ `/zbgg/`、`/p2` 分页 | ⛔ 华为云 WAF 419 验证 | 备源：仅列表可用，需浏览器渲染才能取详情 |
| 中国采购与招标网 `chinabidding` | ⚠️ 首页 200 | ⛔ 深链接 404 | 备源：需再研究详情页 URL 规律 |
| 全国公共资源交易平台 `ggzy.gov.cn` | ⚠️ 首页 200 | ⛔ 页面 JS 二次加载 | 备源：需 headless 浏览器 |
| CEB 公共服务平台 `cebpubservice.com` | ⛔ 搜索界面带 Vaptcha 人机验证 | —— | **弃用** |
| 贵阳市公共资源交易中心 `ggzy.guiyang.gov.cn` | ⛔ 已改版为 zcy | —— | 需按新站结构重新评估 |

**规律**：服务端渲染（SSR）的地方政府站点可直接 HTTP 抓取；带人机验证、WAF 或 JS 二次渲染的站点需要 headless 浏览器（二期能力）。

### 6.2 各站点采集技术要点

**中国政府采购网（已实现）**
- 列表页按公告类型分目录：`/cggg/dfgg/{gkzb 公开招标, zbgg 中标, gzgg 更正, xjgg 询价}/`
- 翻页：第 N 页为 `{path}index_{N}.htm`
- 详情页字段分布在 HTML 中，用正则/标签文本锚点取值（锚点清单见 [`06-数据采集设计.md`](../技术/06-数据采集设计.md) §4.1）
- 附件为详情页中的 `.pdf`/`.doc` 链接 —— 当前**不抓取**

**全国公共资源交易平台（待接入）**
- 列表页可按地区代码筛选：URL 中的 6 位地区码（如 `360000` 江西、`520000` 贵州）
- 详情页 URL 规律：`/information/deal/html/{a|b}/{地区码6位}/{类型4位}/{日期8位}/{hash}.html`
- 内容为静态 HTML，但列表需 JS 二次加载 → 需要 headless 浏览器

**贵州省招标投标公共服务平台（已实现，接口源）**
- 列表接口：`/api/trade/search?pubDate=&pubType=&region=&industry=&prjType=&noticeType=&noticeClassify=&pageIndex=&args=`
- 详情接口：`/api/trade/GetDetail/{Id}`
- 需 Cookie 预热 + `X-Requested-With: XMLHttpRequest`

### 6.3 字段统一映射规律

不同源站对同一概念的叫法不一致，采集时需归一。实测到的差异：

| 统一字段（本项目） | ccgp | ggzy.gov.cn | ztb.guizhou.gov.cn |
|---|---|---|---|
| 项目编号 | 项目编号 | 项目编号 | 招标编号 / 交易编号 / 统一交易码 |
| 预算金额 | 预算金额 | 预算金额 / 最高限价 | 项目预算（单位可能是元或万元） |
