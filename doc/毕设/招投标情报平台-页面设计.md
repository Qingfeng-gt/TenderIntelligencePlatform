## 2. M1 智能站点发现台（admin-web）

```
┌─────────────────────────────────────────────────────┐
│ [种子关键词输入框] 例如: 贵州 弱电 招标              │
│ [地区过滤] 省/市下拉   [数量上限] 10   [开始发现]    │
├─────────────────────────────────────────────────────┤
│ Agent 运行进度（Steps 时间线）                       │
│  ✓ 搜索引擎检索 → 命中 50 条                        │
│  ✓ 抓取首页 HTML → 解析 50 个站点首页              │
│  ▶ LLM 判别是否招投标站点（当前 32/50）             │
│  ○ 抽取站点画像                                       │
│  ○ 健康度评分                                         │
├─────────────────────────────────────────────────────┤
│ 候选站点表格                                        │
│ ☐ | 站点名 | 域名 | 地区 | 健康分 | 推荐适配器       │
│ ☑ | 贵州公共资源交易 | ggzy.guizhou.gov.cn | 92 | ggzy│
│ ☑ | 贵州政府采购网 | ccgp-guizhou.gov.cn | 95 | ccgp │
│ ☐ | 某装修公司招标页 | zhaobiao.xxx.com | 38 | 误判  │
├─────────────────────────────────────────────────────┤
│ [批量入库] [拒绝选中] [查看首页快照]                 │
└─────────────────────────────────────────────────────┘
```

**依赖接口**：`POST /admin-api/discovery/run`（body: seed, region, limit）→ taskId；`GET /admin-api/discovery/progress?taskId=`；`GET /admin-api/discovery/candidates?taskId=`；`POST /admin-api/discovery/approve`。

**前端组件**：`AgentSteps.vue`（Steps 时间线，带实时状态）、`CandidateSiteTable.vue`（候选站点表格）、`HealthScoreBadge.vue`（健康分彩色 badge：≥80 绿、60~80 黄、<60 红）。

> ⚠️ 按 §3.1 降级，健康分已简化为「可访问性 + 是否招投标站」两档，`HealthScoreBadge` 相应简化。

## 4. M3 前台展示（user-web）

**公告列表页 `/notice`**

```
┌─────────────────────────────────────────────────────┐
│ 顶部搜索框（基础检索，调 MySQL LIKE/全文）           │
│ 筛选栏：地区[贵州▼] 金额[全部▼] 采购方式[全部▼]      │
├─────────────────────────────────────────────────────┤
│ 公告卡片列表                                        │
│ ┌───────────────────────────────────────────────┐ │
│ │ [标签chip: 弱电智能化] [标签chip: 贵阳市]      │ │
│ │ 贵阳市教育局弱电智能化改造项目招标公告          │ │
│ │ 发布时间: 2026-10-10  预算: 86.5 万            │ │
│ │ 来源: 贵州政府采购网  [详情] [收藏]            │ │
│ └───────────────────────────────────────────────┘ │
│ [分页]                                              │
└─────────────────────────────────────────────────────┘
```

**公告详情页 `/notice/:id`**：标题、发布时间、来源、正文（HTML 渲染）、附件下载、联系方式；"相关推荐"区块预留位置（丁用语义召回，戊用同标签）。

**我的收藏 `/favorite`**：用户收藏的公告列表、订阅的关键词/地区订阅。

**依赖接口**：`GET /notice/list?keyword=&region=&budgetMax=&tagIds=`；`GET /notice/get?id=`；`POST /notice/favorite/toggle`（**收藏接口尚不存在，需丙补**）。

> ⚠️ 现有实现是 `/notice/list`、`/notice/get`、`/notice/stats`，**挂在 `/admin-api/notice/**` 下靠放行免登录**，不在 `/app-api`。见 §0 第 4 条。

```

├─────────────────────────────────────────────────────┤
│ 方法            | Recall@10 | MRR | 平均耗时          │
```

**前端组件**：`AiSearchBox.vue`（大搜索框 + 魔法棒图标）、`IntentPanel.vue`（LLM 解析结果折叠面板）、`SearchResultCard.vue`（结果卡，带相关度色条和命中方式标签）、`EvalTable.vue`（评测对比表）。
